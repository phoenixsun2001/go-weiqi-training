# 专项强化计划模块实现计划

## 目标
基于 JadenSai 93局 AI 复盘的弱点数据，自动生成个性化训练计划，可追踪进度，可跳转到题库/定式/复盘执行任务。

## 架构
```
AI复盘93局 → 弱点聚合 → 生成4周训练计划 → 每日任务 → 跳转执行 → 标记完成 → 进度追踪
```

## 后端

### 1. 新增数据表（store.py SCHEMA 追加）
```sql
CREATE TABLE IF NOT EXISTS training_task (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    week INTEGER NOT NULL,           -- 第几周(1-4)
    day INTEGER NOT NULL,            -- 第几天(1-7)
    category TEXT NOT NULL,          -- 布局/序盘/中盘/官子/死活/定式
    title TEXT NOT NULL,             -- 任务标题
    description TEXT NOT NULL,       -- 任务说明
    target_module TEXT NOT NULL,     -- problem/joseki/review/practice
    difficulty INTEGER DEFAULT 3,    -- 建议难度
    status TEXT NOT NULL DEFAULT 'pending',  -- pending/done/skipped
    completed_at TEXT,
    sort_order INTEGER DEFAULT 0
);
```

### 2. 新增 `backend/training_plan.py`
- `generate_plan(weakness_summary)`：根据弱点排行生成4周28天训练计划
- `get_weakness_summary()`：聚合93局AI复盘的issues，返回弱点排行
- 计划模板（基于JadenSai的实际数据）：
  - 第1周：布局革命（星位开局、占角、不贴身）→ 定式学习+复盘+题库
  - 第2周：序盘过渡（拆边、不急于战斗）→ 定式+复盘
  - 第3周：中盘减少浮棋（打入/治孤）→ 死活题+复盘
  - 第4周：综合提升（官子+攻杀+实战）→ 全模块综合

### 3. 新增 API 端点（main.py）
- `POST /api/training/generate` — 分析93局+生成计划
- `GET /api/training/tasks` — 获取全部任务（按周/天分组）
- `POST /api/training/task/{id}/status` — 更新任务状态(done/skipped/pending)
- `GET /api/training/progress` — 获取进度统计

## 前端

### 4. 新增 `src/views/TrainingView.tsx`
- 顶部：弱点摘要仪表盘（雷达图风格的评分卡片：布局/序盘/中盘/官子各阶段AI评分）
- 中部：4周训练计划进度条（整体完成率）
- 下部：当日任务列表
  - 每个任务卡片：标题+说明+模块标签+完成按钮
  - 点击跳转到对应模块（题库/定式/复盘）
- 色彩：完成=绿色✅，待完成=蓝色⭕，跳过=灰色⏭
